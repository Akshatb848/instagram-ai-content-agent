# Free-tier usage plan

Run n8n on an already-owned always-on machine behind Tailscale Funnel, use one PostgreSQL/Supabase free project, create at most three Reels weekly, and run one bounded GitHub Actions render at a time. Retain failed Actions artifacts for three days and Cloudinary media for seven days. Stop immediately on quota exhaustion. Never select a paid fallback automatically.

Provider allowances can change; verify them immediately before deployment and use service-level limits. Google Cloud is excluded.

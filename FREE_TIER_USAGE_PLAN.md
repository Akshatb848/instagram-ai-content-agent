# Free-tier usage plan

Run one eligible e2-micro VM for n8n only, one PostgreSQL/Supabase free project, at most three Reels weekly, and one bounded GitHub Actions render at a time. Retain failed Actions artifacts for three days and Cloudinary media for seven days. Stop immediately on quota exhaustion. Never select a paid fallback automatically.

Provider allowances and Google eligibility can change; verify them immediately before deployment and use billing alerts plus service-level limits.
